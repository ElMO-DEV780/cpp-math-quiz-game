# C++ Math Quiz Game 🎮

A console-based Math Quiz Game developed in C++ and designed to run in a Linux terminal. This project was created to practice C++ programming fundamentals and improve problem-solving skills.

## ✨ Features

- Multiple difficulty levels: Easy, Medium, Hard, and Mixed.
- Different mathematical operations.
- Randomly generated math questions.
- Tracks correct and incorrect answers.
- Displays final quiz results.
- Colored terminal output.
- Clears the terminal between screens.

## 🛠️ Technologies Used

- **Language:** C++
- **Environment:** Linux Terminal
- **Compiler:** GCC / G++

## 🚀 Getting Started

### Prerequisites

- A Linux operating system.
- GCC or another compatible C++ compiler.

### Compilation

Clone this repository and navigate to the project directory. Compile the source code using:

```bash
g++ main.cpp -o math-quiz
```

### Run the Game

```bash
./math-quiz
```
